# Store JSON Files

This directory contains the store JSON files used by the web app.

Their download source is the remote directory below:

https://artifact.websoft9.com/release/websoft9/store/

Each `x.json` file in this directory corresponds to a file with the same name in that remote directory.

Examples:

- `catalog_en.json` -> `https://artifact.websoft9.com/release/websoft9/store/catalog_en.json`
- `catalog_zh.json` -> `https://artifact.websoft9.com/release/websoft9/store/catalog_zh.json`
- `product_en.json` -> `https://artifact.websoft9.com/release/websoft9/store/product_en.json`
- `product_zh.json` -> `https://artifact.websoft9.com/release/websoft9/store/product_zh.json`
