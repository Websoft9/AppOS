# AGENTS.md — AppOS

## Build & Verify

```bash
make build          # backend binary + web dist (always after changes)
make lint           # golangci-lint + eslint + typecheck (CI: `make lint strict`)
make test backend   # all Go tests
make test web       # all Vitest tests
make test backend-targeted TARGET=TestName   # single Go test
npx vitest run src/path/to/file.test.tsx     # single web test
```

After OpenAPI/route changes: `make openapi-sync`

## Architecture

Monorepo: Go backend (`backend/`) + React/Vite frontend (`web/`), built into one Docker image.

- **Backend**: PocketBase framework (auth, DB, admin UI) + custom Go routes (`backend/domain/routes/`).
  - Domain logic in `backend/domain/`, persistence in `backend/infra/persistence/`.
  - Instance/connector templates live in `backend/domain/resource/{instances,connectors}/templates/` via Go `embed.FS`.
  - Custom API routes return raw JSON — no PocketBase collection wrapper.
- **Frontend**: React 19 + TanStack Router (file-based, `web/src/routes/`) + TailwindCSS 4.
  - `routeTree.gen.ts` is auto-generated by TanStack Router Vite plugin. Do not edit manually.

## API Client (`pb.send`)

The PocketBase SDK client (`import { pb } from '@/lib/pb'`) is the only HTTP client. It returns **raw JSON** for custom routes, not PocketBase-wrapped responses.

```ts
// GET list → direct array
const items = await pb.send<InstanceRecord[]>('/api/instances', { method: 'GET' })
// GET single → direct object
const item = await pb.send<InstanceRecord>(`/api/instances/${id}`, { method: 'GET' })
// Mutations (POST/PUT/DELETE) require superuser on /api/instances, /api/connectors, etc.
```

## Resource Pages Pattern

All resource list pages (service-instances, connectors, servers, ai-providers, platform-accounts) share `<ResourcePage config={...}>`. Each page follows the same pattern:

1. `mapRow(rawApiItem, templatesById, monitors, t)` — flattens nested `config` to top level, adds computed fields (`host`, `port`, `credential_use_secret`, `enabled_status`, etc.)
2. `buildPayload(mappedRow, templatesById, t)` — reconstructs the API payload from mapped (flattened) row data
3. `buildColumns(t, onToggleEnabled)` — table column definitions with render callbacks

**Critical rule**: `buildPayload` functions expect **mapped row data** (with flattened config fields at top level), NOT raw API responses. If you fetch a single item via `pb.send`, always map it through `mapRow` before passing to `buildPayload`.

## Backend Route Permissions

Mutations on resources are superuser-only:

```go
mutations.Bind(apis.RequireSuperuserAuth())
mutations.PUT("/{id}", handleInstanceUpdate)
```

## Testing

- Go tests: use `*_test.go` alongside source files. Repository tests need PocketBase app instance.
- Web tests: Vitest + jsdom. Mock `@/lib/pb` via `vi.mock`. Test files colocated with source as `-*.test.tsx`.
- E2E tests in `tests/` (container smoke tests).

## Style

- **Prettier**: no semicolons, single quotes, tabWidth 2, printWidth 100 (`web/.prettierrc`)
- **Go**: `gofmt` standard formatting
- **ESLint**: flat config, `no-explicit-any` and `exhaustive-deps` disabled
